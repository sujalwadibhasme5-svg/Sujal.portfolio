PERSONAL PORTFOLIO WEBSITE

Files:
- index.html
- style.css
- assets/profile.svg
- assets/project-portfolio.svg
- assets/project-game.svg

HOW TO RUN:
1. Extract the ZIP file.
2. Keep index.html, style.css, and the assets folder together.
3. Open index.html in Chrome, Edge, Firefox, or another browser.

BEFORE SUBMISSION, PERSONALIZE:
- Replace [Your College Name], [Branch / Department], and [College Name].
- Replace your.email@example.com in both the visible email and the form action.
- Replace the illustrated profile placeholder at assets/profile.svg with your own photo
  (keep the filename profile.svg only if using an SVG; otherwise update the img src in index.html).
- Update project descriptions and social profile links to your real work/accounts.
- Skill bars are illustrative self-assessments; adjust them honestly.

FORM NOTE:
The contact form uses HTML required-field and email validation. With no JavaScript or backend,
the submit button opens the visitor's default email application using a mailto action.
